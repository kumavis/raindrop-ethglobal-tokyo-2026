# tendril — script

A brand exploration: the same mechanism as Raindrop, framed as **living, adaptive governance**. DAOs are the old
way, a machine that only moves when someone cranks it. This is the new way, an organism (a slime mold) that is
always sensing and re-routing. Keeps the Raindrop design system's type and palette; the rain motif is replaced by
a slime-mold network drawn in code. ~135 s. Timings match `video.html`.
